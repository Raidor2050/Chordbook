# Chordbook

A polished, shared online guitar songbook. Browse and search songs, open a
song and see its chords by section with generated chord diagrams, guitar
fretboard and piano maps for soloing — and add songs that everyone can see.

Built from the tiny static **setlist** project (ten songs, `data/songs.json`,
an SVG chord-diagram engine, improvisation maps) into a production web
application with a persistent, multi-user song library.

## Features

- **Shared song library** — a real database (Supabase/Postgres) stores songs;
  a song added by one visitor appears for everyone. Without a backend the app
  still works as a persistent local draft in each browser.
- **Browse + search** — fast fuzzy search over title, artist, album and
  chords, plus filters for artist, key, difficulty and tuning. Try
  `oasis wonder`.
- **Chord retrieval providers** — pluggable abstraction (`metadata`, local
  key analysis, manual entry). Metadata comes from a public key-free API;
  chord progressions are generated locally and clearly labelled; published
  charts can be pasted in by the user. If automatic retrieval can't help, the
  UI degrades gracefully to manual entry.
- **Generated chord diagrams** — all diagrams are drawn client-side from a
  fingering dictionary (C, Cm, A7, Am7, Fmaj7, Cadd9, Dsus2…). The `/chords`
  library page shows every shape.
- **Song page** — metadata (key, capo, tuning, difficulty), chord list,
  diagram row, tab-style chord/lyric sheets per section, improvisation maps,
  source attribution.
- **Mobile + keyboard friendly** — responsive layout, `/` focuses search,
  accessible controls and contrast.

## Quick start

```sh
npm install
npm run dev        # development server
npm run build      # production build into dist/
npm test           # unit tests
npm run test:e2e   # end-to-end browser tests (needs `npx playwright install`)
```

`npm run dev` runs in **local draft mode** (songs saved in the browser's
IndexedDB). See `docs/backends.md` to activate the **shared library** via
Supabase.

## Repository layout

```
.github/workflows/pages.yml   Build + deploy to GitHub Pages
src/                          React app (Vite)
  api/                        Storage providers + chord retrieval providers
  components/                 UI components
  data/seedSongs.js           The ten songs migrated from setlist
  lib/                        Pure logic: chords, diagrams, search, keys, …
supabase/
  schema.sql                  Database schema + RLS + write functions
  seed.sql                    Seed songs (generated by scripts/export-seed-sql.mjs)
scripts/                      Build helpers
docs/backends.md              Backend setup guide
.env.example                  Safe public config placeholders
```

## Deployment

Pushing to `main` builds and publishes the app to GitHub Pages via GitHub
Actions. GitHub Pages hosts only the frontend; songs live in the database.

## Data

Thirty songs from the original set (More Than Words, Fix You, Yellow,
Sunflower, How to Save a Life, All I Want, Secrets, Demons, Iris, The
Scientist — by Extreme, Coldplay, Post Malone, The Fray, Kodaline,
OneRepublic, Imagine Dragons, Goo Goo Dolls) ship as seed data. Song titles
and lyrics remain the property of their rights holders.
